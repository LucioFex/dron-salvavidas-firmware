# Configuración de ArduPilot

Acá van los parámetros de la controladora, los scripts y las notas de configuración del dron.

Pendiente de definir:

- Failsafes: volver a la base si se corta el enlace, si baja la batería o si se pierde el GPS.
- Salida del servo de la cápsula liberadora.
- Salidas de la luz estroboscópica y del buzzer.
- Límites de velocidad, altura y geocerca para volar sobre el agua.

Antes de cualquier vuelo real, la secuencia completa se prueba en el simulador de ArduPilot (SITL).
